# GeminiClone

A frontend practice project inspired by Gemini-style chat UI and interactions.

## Overview

GeminiClone was built for frontend practice, focusing on creating a clean chat interface, responsive layout, and smooth user experience using modern React tooling.

## Live Demo

[View Live Demo](https://your-live-demo-link.com)

## Features

- Gemini-inspired chat interface
- Responsive design for different screen sizes
- Reusable React components
- Clean and minimal UI layout

## Tech Stack

- React
- Vite
- JavaScript (ES Modules)
- Tailwind CSS
- Lucide React
